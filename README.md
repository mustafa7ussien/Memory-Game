# Memory Scramble Game

A modern, interactive memory card matching game built with vanilla HTML, CSS, and JavaScript. Test your memory by matching pairs of cards before time runs out!

## 🎮 Features

- **Dynamic Grid System**: Customizable board size (2x2 to 8x8)
- **Preview Mode**: Brief preview of all cards before gameplay starts
- **Timer System**: Configurable countdown timer with danger state
- **Progress Tracking**: Real-time HUD showing time, pairs matched, and moves
- **Card Animations**: Smooth flip animations and match effects
- **Responsive Design**: Works on desktop and mobile devices
- **Visual Effects**: Starfield background and glowing effects

## 🚀 How to Build and Execute

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- No build tools or dependencies required!

### Running the Game

1. **Clone the repository**
   ```bash
   git clone https://github.com/mustafa7ussien/Memory-Game.git
   cd Memory-Game
   ```

2. **Open the game**
   - Simply double-click `index.html` to open in your default browser
   - OR right-click `index.html` → Open with → Choose your browser

3. **Start playing!**

## 📖 How to Play

1. **Configure Game Settings**
   - Set the number of **Rows** (2-8)
   - Set the number of **Columns** (2-8)
   - Set the **Time Limit** in seconds (10-600)
   - Note: Rows × Columns must be an even number for card pairs

2. **Click "Play"**
   - All cards will be shown briefly (preview phase)
   - A countdown will appear
   - Cards will flip back when the countdown ends

3. **Match the Pairs**
   - Click any card to flip it
   - Click a second card to find a match
   - If cards match, they stay flipped
   - If they don't match, they flip back after a short delay

4. **Win Conditions**
   - Match all pairs before time runs out to win!
   - If time expires, the game ends

5. **Controls**
   - **SETUP** button: Return to configuration screen
   - **PLAY AGAIN** button: Restart with same settings (after game ends)
